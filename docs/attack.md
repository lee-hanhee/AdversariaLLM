# Attack overview

Methods in the incremental PR plan, including the Direct baseline and held
methods. Planned and held entries link to author repositories; their adapters
are not present on this branch yet.

| Attack | What it does | How it works | Status | Code / source |
| --- | --- | --- | --- | --- |
| Direct | Provides an unmodified-prompt baseline. | Sends the original user request to the target and records its response. | PR 01 | [Adapter](../adversariallm/attacks/direct.py) |
| FlipAttack | Disguises a request by flipping text. | Reverses words or characters, then gives the target instructions to reconstruct and answer it. Optional guidance adds step-by-step instructions and examples. | PR 02 | [Adapter](../adversariallm/attacks/flip_attack.py), [author builder](../adversariallm/attacks/author_implementations/flip_attack/flip_attack.py), [verification](../verification/flip_attack/SOURCE.json) |
| EquaCode | Presents a request as equations or code. | Inserts the request into author templates that ask the target to solve equations, complete code, or combine both. | PR 03 | [Adapter](../adversariallm/attacks/equacode.py), [author templates](../adversariallm/attacks/author_implementations/equacode/equacode_prompts.py), [verification](../verification/equacode/SOURCE.json) |
| GTA | Uses a game-theoretic interrogation scenario. | A Police attacker alternates between Thomas and Marcos, each with separate history; an author Judge feeds ratings into later questions. | PR 04 | [Adapter](../adversariallm/attacks/gta.py), [author driver](../adversariallm/attacks/author_implementations/gta/gta_driver.py), [verification](../verification/gta/SOURCE.json) |
| Mousetrap | Hides a request behind layered text transformations. | Randomly rewrites text and supplies decoding steps; tries three attempts per chain length, using the author judge to decide when to stop. | PR 05 | [Adapter](../adversariallm/attacks/mousetrap.py), [author pipeline](../adversariallm/attacks/author_implementations/mousetrap/mousetrap_pipeline.py), [verification](../verification/mousetrap/SOURCE.json) |
| QueryAttack | Rewrites a request into code or query-like text. | A helper extracts and translates the request into a selected language/template, then the target receives the assembled prompt. | PR 06 | [Adapter](../adversariallm/attacks/query_attack.py), [author translator](../adversariallm/attacks/author_implementations/query_attack/translator.py), [verification](../verification/query_attack/SOURCE.json) |
| TAP | Searches a tree of candidate attack prompts. | An attacker model proposes branches; an evaluator prunes off-topic or weaker candidates and scores target responses. | PR 08, this branch | [Adapter](../adversariallm/attacks/tap.py), [author search](../adversariallm/attacks/author_implementations/tap/main_TAP.py), [verification](../verification/tap/SOURCE.json) |
| WordGame / WordGame+ | Replaces a selected word with a hint-based puzzle. | Preserves JBF selection, rewrites, fallback, masking, and optional auxiliary questions. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/wordgame.py), [verification](../verification/wordgame/SOURCE.json) |
| AIM | Encodes characters into 1-based alphabet indices. | Converts letters to `1:`..`26:` indices (`AIM`, `AIM+FWO`, `AIM+FCW`) with a decoding system instruction. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/aim.py), [verification](../verification/aim/SOURCE.json) |
| DeepInception | Embeds requests in nested sci-fi/dream layers. | Wraps the goal in a multi-layer narrative with configurable `scene_type`, `character_number`, and `layer_number`. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/deep_inception.py), [verification](../verification/deep_inception/SOURCE.json) |
| HILL | Reframes imperative queries into exploratory questions. | Uses an attacker helper with few-shot examples to convert requests into academic-style questions. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/hill.py), [verification](../verification/hill/SOURCE.json) |
| ISA | Shifts linguistic intent into inquiry framing. | Helper normalizes the query into `"How to"` form, then applies one of five linguistic shifts (`person`, `tense`, `voice`, `mood`, `question`). | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/isa.py), [verification](../verification/isa/SOURCE.json) |
| Past-Tense | Reformulates requests into past tense with restarts. | Samples up to `n_restarts` past-tense rewrites, queries the target at temperature 1.0, and stops early on a GPT-4 `Rating: [[10]]` judge score. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/past_tense.py), [verification](../verification/past_tense/SOURCE.json) |
| SCP | Injects benign context to decay safety thresholds. | Generates a benign opposite sentence via an attacker helper, then nests the inverted task inside `base`, `code`, `json`, or `code_json` templates. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/scp.py), [verification](../verification/scp/SOURCE.json) |
| ABJ | Multi-round analyzing-based jailbreak with toxicity adjustment. | Transforms the request into neutral criminal-analysis data, samples `max_attack_rounds`, and iteratively adjusts toxicity via refusal feedback. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/abj.py), [verification](../verification/abj/SOURCE.json) |
| PAIR (Hosted) | Multi-stream iterative prompt refinement. | Runs `n_streams` parallel attacker-target-judge loops for `n_iterations`, truncating history to `keep_last_n` and stopping at `success_threshold`. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/pair_hosted.py), [verification](../verification/pair_hosted/SOURCE.json) |
| PUZZLED | Masks harmful keywords inside word puzzles. | Extracts sensitive words, generates clues via an attacker helper, and builds `anagram`, `word_search`, or `crossword` puzzles. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/puzzled.py), [verification](../verification/puzzled/SOURCE.json) |
| MAJIC | Q-learning multi-strategy prompt rewriting loop. | Updates a strategy transition matrix over `max_queries` iterations using `attacker` rewrites and `judge` rewards. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/majic.py), [verification](../verification/majic/SOURCE.json) |
| TRIAL\* | Interactive trolley-dilemma multi-turn escalation. | Extracts `theme`/`action`/`goal`, frames a trolley dilemma, and conducts iterative follow-up turns evaluated by a judge. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/trial.py), [verification](../verification/trial/SOURCE.json) |
| AIR\* | Formal outline expansion across two target turns. | Rewrites the query into an outline (`k2`–`k6`), collects turn-1 target expansion, and submits turn-2 completion. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/air.py), [verification](../verification/air/SOURCE.json) |
| SATA | Masked-token / element-position perturbation. | Runs `elp` (commendatory element lookup) or `mlm` (wiki-context masking) at `sw`/`sp`/`mw`/`mp` granularity. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/sata.py), [verification](../verification/sata/SOURCE.json) |
| Response Attack | Direct or scaffolding response injection (`RA-DRI*` / `RA-SRI*`). | Uses an auxiliary helper to generate a harmless turn and an injected assistant prefix before querying the target. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/response_attack.py), [verification](../verification/response_attack/SOURCE.json) |
| RTS-Attack | Scenario-wrapped instruction classification. | Classifies Process vs. Sample intent, wraps in a `scenario_genre`, and optionally enforces JSON output. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/rts.py), [verification](../verification/rts/SOURCE.json) |
| ReNeLLM | Rewrite + scenario nesting with judge gating. | Applies rewrite operators via `attacker`, verifies harmfulness preservation via `judge`, and nests inside code/table/story frames. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/renellm.py), [verification](../verification/renellm/SOURCE.json) |
| JAIL-CON | Token-interleaved obfuscation (`CVT` / `CIT`). | Interleaves harmful goal tokens with offline benign auxiliary tasks using `{}` / `<>` / `[]` separators. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/jailcon.py), [verification](../verification/jailcon/SOURCE.json) |
| TrojFill | Template-filling obfuscation (`Caesar` / `Base64` / `splitting`). | Uses an attacker helper to transform keywords and assemble template-filling instructions. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/trojfill.py), [verification](../verification/trojfill/SOURCE.json) |
| JailExpert | Experience-indexed multi-strategy mutation. | Retrieves prior jailbreak experiences via `/embeddings` clustering and applies `MutationEngine` via `attacker`. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/jailexpert.py), [verification](../verification/jailexpert/SOURCE.json) |
| BPJ | Boundary point random-prefix search. | Probes target boundary points across noise levels within `query_budget`. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/bpj.py), [verification](../verification/bpj/SOURCE.json) |
| CC-BOS | Classical Chinese bio-inspired search (FOA). | Optimizes 8 classical Chinese strategy dimensions with `attacker`, `translation`, and `judge` models. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/cc_bos.py), [verification](../verification/cc_bos/SOURCE.json) |
| Intent Laundering | Connotation neutralization and context transposition. | Reframes malicious intent into abstract/fictional contexts via `attacker` helper. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/intent_laundering.py), [verification](../verification/intent_laundering/SOURCE.json) |
| S2C | Structured semantic cloaking. | Applies contextual reframing, fragmentation, and clue-guided obfuscation (`char_noise`/`caesar`/`base64`/etc.). | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/s2c.py), [verification](../verification/s2c/SOURCE.json) |
| TOMBRAIDER | Multi-turn historical context escalation. | Inspector constructs historical framing while Attacker steers toward modern simulation across `max_rounds`. | Integrated (third-party JBF source) | [Adapter](../adversariallm/attacks/tombraider.py), [verification](../verification/tombraider/SOURCE.json) |
| CoT Forgery | Adds fabricated reasoning or policy text to a request. | A helper generates the forgery, which is appended to the target prompt to encourage answering. | Held for fidelity audit | [Author source](https://github.com/role-confusion/prompt-injection-as-role-confusion/tree/ec333c40fd43fe991e1ebf66765051b6d7e35784) |
